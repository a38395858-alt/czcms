# CZCMS 中文管理后台页面功能开发文档

> 文档版本：V1.0  
> 更新日期：2026-08-26  
> 适用范围：CZCMS 中文管理后台、站点本地预览和正式域名接入  
> 关联文档：[产品与开发需求](./cms-product-requirements.md)、[技术选型](./cms-technology-selection.md)、[目录 API](./catalog-api.md)、[安全运维](./security-operations.md)

## 1. 文档目标

本文档把 CZCMS 的产品需求落实为页面级开发规格，供产品、前端、Go 后端、测试和运维共同使用。

本文档重点回答以下问题：

- 每个页面展示什么数据；
- 页面有哪些按钮、筛选器、表格、表单和详情视图；
- 每个操作需要什么权限；
- 数据状态如何变化；
- 哪些操作必须记录审计、执行二次认证或进入异步任务；
- 加载、空数据、失败、无权限和数据冲突时如何处理；
- 开发完成后如何验收。

本文档描述目标功能，不表示所有功能当前已经完成。开发状态必须由任务系统、版本计划和自动测试结果单独管理。

## 2. 产品边界和统一原则

### 2.1 产品边界

- 后台界面固定使用中文。
- 公开前台支持动态多语言；语言、Locale、国家市场和模板不得写死在前端代码中。
- 一个站点可以启用多种语言，每种语言必须可以独立绑定一整套模板。
- 开发环境中，每个多语言站点使用独立 localhost 端口测试，例如后台为 `localhost:8080`，站点依次为 `localhost:8081`、`localhost:8082`。
- 生产环境通过主域名和别名域名访问，不启动 localhost 独立预览监听器。
- 公开前台输出服务端生成的原生 HTML；后台允许使用原生 JavaScript 和轻量 UI 组件增强交互。
- AI 功能执行语境本土化重写，不做逐句机械翻译。

### 2.2 页面统一布局

所有登录后页面统一包含：

- 左侧主导航；
- 顶部站点切换器；
- 全局搜索；
- 通知入口；
- 当前用户与账户菜单；
- 页面标题、说明和唯一主要操作；
- 加载、错误、空状态和权限不足状态；
- Toast、确认提示和冲突提示。

页面不得把重要操作隐藏在只能通过鼠标悬停发现的位置。主要操作固定出现在页面标题区域，行级低频操作使用操作菜单。

### 2.3 统一数据交互规则

- 列表接口默认分页，禁止一次返回全部大数据。
- 分页默认 20 条，可选择 20、50、100 条；最大单页 100 条。
- 搜索输入 300 毫秒防抖，服务端必须使用索引或搜索服务。
- 列表筛选状态写入 URL 查询参数，刷新页面后保留。
- 列表排序必须由服务端完成，不在浏览器中对不完整分页数据排序。
- 编辑记录使用 `version` 乐观锁；发生版本冲突返回 `409`，不得静默覆盖。
- 所有时间在数据库保存 UTC，后台按管理员时区显示并明确时区。
- 所有写请求执行权限、数据范围、CSRF、Origin、字段白名单和大小限制校验。
- 所有批量操作先显示影响数量；超过 100 条的任务必须异步执行。
- 删除优先采用停用、归档、回收站或延迟删除，避免不可恢复的物理删除。

### 2.4 统一页面状态

每个页面必须实现以下状态：

| 状态 | 页面表现 | 必须提供的动作 |
|---|---|---|
| 首次加载 | 与最终布局相似的骨架屏 | 无 |
| 空数据 | 解释该模块用途和创建第一条数据的方法 | 主要创建按钮 |
| 搜索无结果 | 保留筛选条件并说明没有匹配项 | 清空搜索、重置筛选 |
| 接口失败 | 显示可理解的错误，不输出内部堆栈 | 重试、复制请求 ID |
| 无权限 | 隐藏未授权按钮并显示权限说明 | 返回上一页 |
| 会话过期 | 保存未提交表单草稿到本地后跳转登录 | 重新登录 |
| 版本冲突 | 保留用户输入并说明数据已更新 | 比较差异、重新加载 |
| 异步处理中 | 显示任务 ID、进度和可离开页面说明 | 查看任务 |

### 2.5 权限代码规划

第一版沿用已有 RBAC 权限，并逐步细分高风险权限。

| 权限 | 用途 |
|---|---|
| `dashboard.view` | 进入后台并查看授权范围概览 |
| `sites.manage` | 管理授权站点、域名和站点语言绑定 |
| `languages.manage` | 管理语言库、Locale 和回退规则 |
| `content.read` | 查看授权站点与 Locale 内容 |
| `content.write` | 创建和编辑内容草稿 |
| `content.review` | 审核、退回内容，目标权限 |
| `content.publish` | 发布和撤回内容，目标权限 |
| `templates.manage` | 上传、验证、绑定和回滚模板 |
| `seo.manage` | 修改页面级与站点级 SEO |
| `localization.manage` | 发起和审核 AI 本土化任务，目标权限 |
| `urls.manage` | 管理路由和重定向，目标权限 |
| `media.read` | 查看媒体库 |
| `media.upload` | 上传和编辑媒体 |
| `media.delete` | 删除无引用媒体，目标权限 |
| `publishing.manage` | 创建发布、刷新缓存和回滚 |
| `jobs.manage` | 重试、取消和处理死信任务 |
| `users.manage` | 管理用户、角色和数据范围 |
| `audit.read` | 查看审计日志 |
| `system.view` | 查看系统状态和只读配置 |
| `system.manage` | 修改 AI 提供方和其他系统级配置 |
| `backup.manage` | 创建、下载和验证加密备份 |

## 4. 首次安全设置页面

### 4.1 页面目标

只允许在系统尚未初始化时创建第一个系统所有者。创建成功后永久关闭该入口。

### 4.2 表单字段

| 字段 | 必填 | 规则 |
|---|---|---|
| 管理员用户名 | 是 | 3–64 位，仅允许字母、数字、点、下划线和连字符 |
| 显示名称 | 是 | 1–100 个字符 |
| 邮箱 | 否 | 最大 254 字符，填写时校验邮箱格式 |
| 密码 | 是 | 至少 12 位，通过服务端密码策略校验 |
| 确认密码 | 是 | 必须与密码一致 |
| 安装令牌 | 按配置 | 生产或非本机安装时必须提供 |

### 4.3 安全要求

- 页面只在 `setup_state.completed=0` 时返回。
- 默认只允许本机访问；生产环境必须同时校验安装令牌。
- 密码使用 Argon2id 保存，禁止记录明文、请求体或密码摘要到日志。
- 提交执行 CSRF、Origin、IP 限流和最大请求体限制。
- 创建系统所有者、分配所有权限和全站点/全语言范围必须处于同一事务。
- 创建成功写入审计事件并跳转登录页。

### 4.4 验收标准

- 同一数据库只能成功执行一次初始化。
- 密码不合规、令牌错误、CSRF 错误和非本机未授权请求均不能创建账号。
- 初始化完成后访问 `/setup` 必须跳转登录页。

## 5. 登录与账户安全页面

### 5.1 登录页

页面字段：用户名、密码、MFA/恢复码、登录后跳转地址。

功能要求：

- 用户名不区分大小写。
- 登录失败使用统一提示，避免泄露账号是否存在。
- IP 与用户名分别限流。
- 连续失败触发账户锁定；锁定时间和失败次数可配置。
- 启用 MFA 的账号必须验证 TOTP 或一次性恢复码。
- 登录成功轮换会话 ID、设置 Secure/HttpOnly/SameSite Cookie，并记录审计日志。
- `next` 只接受站内安全路径，禁止开放重定向。

### 5.2 我的账户

展示：用户名、显示名称、邮箱、角色、授权站点/语言、MFA 状态、最近登录、当前会话。

用户可以：

- 修改自己的显示名称和邮箱；
- 修改密码；
- 启用 MFA；
- 查看、重新生成恢复码；
- 退出当前会话；
- 注销其他会话。

修改密码、关闭 MFA、重新生成恢复码必须再次输入当前密码；高权限用户还需 MFA。

### 5.3 MFA 启用流程

1. 再次验证当前密码。
2. 服务端生成临时密钥并加密保存。
3. 页面显示二维码和手工密钥。
4. 用户输入连续有效的 TOTP 验证码。
5. 服务端正式启用 MFA，并一次性显示恢复码。
6. 用户确认已保存恢复码后完成。

## 6. 全局导航、搜索和通知

### 6.1 站点切换器

- 只显示当前用户有权访问的站点。
- 显示站点名称、市场、运行状态和当前选择标记。
- 切换后刷新控制台和各模块默认筛选范围。
- 当前站点保存到本地存储，但服务端不得信任浏览器保存的站点 ID。
- 用户失去站点权限时自动回退到第一个可访问站点。

### 6.2 全局搜索

搜索范围包括：

- 后台功能菜单；
- 内容标题、Slug 和内容 ID；
- 媒体文件名；
- URL 与重定向；
- 发布和任务 ID；
- 用户名；
- 快捷操作。

搜索结果按类型分组，显示站点和语言范围。用户不得搜索到无权限数据。

### 6.3 通知中心

通知类型：发布失败、任务失败、安全告警、待审核内容、模板检查失败、备份失败、域名/证书异常和系统升级提醒。

通知支持：未读计数、按类型筛选、标记已读、全部已读、打开关联对象。删除通知只影响当前用户，不删除关联审计记录。

## 7. 控制台页面

### 7.1 页面目标

让管理员在一个页面判断站点、内容、本土化、发布、安全和基础服务是否正常，并快速进入待处理任务。

### 7.2 顶部状态指标

| 指标 | 口径 | 点击行为 |
|---|---|---|
| 站点总数 | 当前权限范围内站点 | 打开站点管理 |
| 待审核 | 当前范围内 `review` 内容 | 打开内容待审核筛选 |
| AI 待审核 | 已生成但未人工确认的本土化版本 | 打开 AI 本土化 |
| 发布失败 | 最近 24 小时失败且未解决的发布 | 打开发布失败筛选 |
| 缓存命中率 | 最近 15 分钟页面缓存命中率 | 打开性能设置 |
| 安全告警 | 未处理高风险登录或配置事件 | 打开审计日志 |

统计数据必须来自聚合表、缓存或监控指标，不允许每次打开控制台执行全表扫描。

### 7.3 主要区域

- **站点运行概览**：站点状态、域名、localhost 端口、启用语言、最后发布、健康检查。
- **需要处理**：按严重级别列出发布失败、内容待审、模板异常、DNS 异常和备份失败。
- **最近内容**：标题、站点、Locale、状态、负责人、更新时间。
- **最近发布**：发布 ID、范围、页面数、耗时和状态。
- **系统健康**：SQLite、Redis、任务队列、文件存储、备份和磁盘空间。

### 7.4 快捷操作

新建内容、发起 AI 本土化、运行 SEO 检查、创建发布、上传媒体。

按钮按权限显示；没有任何写权限的用户只显示只读概览。

### 7.5 验收标准

- 所有指标严格受站点/Locale 权限范围约束。
- 告警点击后进入带预设筛选条件的对应页面。
- 单个下游服务失败不得导致整个控制台不可用。
- 正常数据量下首屏接口 P95 不超过 500 毫秒。

## 8. 站点管理页面

### 8.1 列表页

顶部指标：站点总数、运行中、维护中/待处理、绑定正式域名数。

筛选条件：运行状态、国家市场、有无正式域名、DNS 状态、是否有发布异常、创建时间。

列表字段：

| 字段 | 说明 |
|---|---|
| 站点 | 名称、代码、ID |
| 国家市场 | 市场代码和显示名称 |
| 访问地址 | 主域名；无主域名时显示 `localhost:{port}` |
| 语言 | 已启用语言数量 |
| 模板完整度 | 已启用语言中已绑定有效模板的比例 |
| 状态 | 运行中、维护中、已停用 |
| 最后发布 | 成功时间或失败标记 |
| 最近更新 | 配置更新时间 |

行级快捷操作：编辑、预览、删除；“预览”打开该站点独立的 localhost 端口，“删除”采用安全停用并保留内容、配置与审计数据。扩展操作继续支持打开正式站、复制站点、进入语言绑定、进入发布记录和切换维护状态。

批量操作：复选框逐行选择、当前筛选结果全选、批量删除、进入维护、退出维护、刷新缓存和运行健康检查。批量删除必须先显示站点数量和影响说明，逐站执行权限、版本与审计校验；第一版采用安全停用，不物理删除关联内容。

### 8.2 新建/编辑站点

基础字段：

- 站点名称；
- 站点代码；
- 国家市场代码；
- 默认语言；
- 初始模板（仅显示已通过安全检查并完成编译的模板，默认选择 Global Route；创建后自动绑定到默认语言）；
- 运行状态；
- 本地预览端口；
- 时区；
- 默认日期/数字格式；
- 默认分页数量；
- 联系信息和法律信息配置引用。

编辑站点还提供“SEO 设置”二级页签：

- 默认站点 Title：用于首页 `<title>`，最多 200 个字符；内容页存在独立 SEO 标题时不覆盖内容设置；
- 网站 Icon：上传并本地化 PNG/JPEG，展示实时预览、文件名和尺寸；仅接受方形 16–2048 像素图片，服务端重新验证真实 MIME、尺寸和媒体 ID；
- 上传的 Icon 进入媒体中心并保留引用关系，保存站点后前台所有页面输出 `rel="icon"` 与 `apple-touch-icon`；
- 没有 `seo.manage` 时页签只读或不显示写入控件；修改后沿用站点版本并发检查和审计日志。

“模板与预览”区域顶部使用“选择语言”下拉框。下拉项显示语言名称、Locale 和启用状态；切换后只显示该语言独立的模板选择、启用开关、预览 iframe 和前台地址，模板绑定仍按语言单独保存。

规则：

- 站点代码全局唯一，创建后修改必须进行 URL 与缓存影响检查。
- `local_port` 全局唯一，不能使用管理后台端口 8080。
- 新建站点自动建议当前最大本地端口加一。
- 保存端口后动态启停对应监听器，无需重启服务。
- 停用站点关闭本地监听，但保留全部历史数据。

### 8.3 本地测试区域

展示：固定预览地址、端口状态、最后启动时间、打开预览按钮。

行为：

- `http://localhost:{local_port}/` 只路由到指定站点。
- 本地端口只开放公开页面、站点静态资源和健康检查，不开放 `/admin`。
- 本地响应强制 `X-Robots-Tag: noindex, nofollow` 和 `Cache-Control: no-store`。
- 端口被其他程序占用时显示明确错误，站点配置保留但状态标记为“监听失败”。

### 8.4 正式域名区域

每个站点支持一个主域名和多个别名域名。

域名字段：hostname、类型、别名是否 308 跳转主域名、DNS 状态、解析地址、最后检查时间、HTTPS 状态、证书到期时间。

功能：

- 添加主域名或别名；
- 将别名设为主域名；
- 删除绑定；
- 检查公开 A/AAAA 解析；
- 复制建议的 A、AAAA 或 CNAME 配置；
- 检查 HTTP/HTTPS 可达性；
- 配置旧域名到新主域名的 308 跳转。

DNS `resolved` 只表示存在公开解析记录，不代表一定指向当前服务器。上线前必须另外检查反向代理和 HTTPS 证书。

### 8.5 站点详情标签页

- **概览**：状态、语言、域名、模板、最后发布和健康告警。
- **语言与模板**：启用语言、Locale、URL 前缀、模板绑定和完整度。
- **域名与环境**：本地端口、正式域名、CDN、媒体域名和 HTTPS。
- **SEO 默认值**：标题模板、Canonical 域名、robots、Sitemap。
- **发布设置**：输出目录、缓存策略、增量发布和回滚保留数。
- **高级设置**：时区、法律信息、Cookie 策略和功能开关。

### 8.6 权限与审计

- 读取受站点范围约束。
- 修改需要 `sites.manage` 且拥有该站点 `*` Locale 管理范围。
- 域名、端口、状态和默认语言变更写审计日志。
- 主域名变更、停用生产站点和删除域名必须二次确认。

### 8.7 验收标准

- 可创建两个站点并分别通过 `localhost:8081`、`localhost:8082` 访问。
- 相同域名或端口不能绑定给两个站点。
- 无站点权限用户不能通过猜测 ID 修改站点或域名。
- 别名 308 跳转保留路径和查询参数。

## 9. 语言管理页面

### 9.1 列表页

顶部指标：预置语言数、全局启用数、已绑定站点数、RTL 语言数。

筛选：启用状态、方向、站点、是否缺少模板、是否有待本土化内容。

列表字段：中文名称、本地名称、代码、默认 Locale、方向、启用站点数、内容完成度、模板完成度、状态。

### 9.2 添加/编辑语言

字段：

- 语言代码；
- 中文名称；
- 本地名称；
- 默认 Locale；
- 文字方向 LTR/RTL；
- 默认回退语言；
- 默认 URL 前缀；
- 日期、数字和货币格式；
- 默认 `hreflang`；
- 是否全局启用。

语言代码创建后不得直接改成另一个含义不同的语言。需要更换代码时创建新语言并执行迁移任务。

### 9.3 站点语言绑定

字段：站点、Locale、URL 模式、URL 前缀、启用状态、模板套装、回退语言、SEO 默认值、内容完成度。

支持三种 URL 模式：

- 同域名目录：`example.com/de/`；
- 语言子域名：`de.example.com`；
- 独立国家域名：`example.de`。

第一版可以只启用一种模式，但数据结构必须保留模式字段。

### 9.4 启用前检查

启用站点语言前必须检查：

- Locale 唯一；
- URL 前缀/域名不冲突；
- 模板套装完整且通过安全验证；
- 首页、404、列表和详情基础模板存在；
- Canonical 与 `hreflang` 策略可生成；
- 至少存在首页或明确的空站策略。

### 9.5 停用行为

- 从前台语言切换器、Sitemap 和 `hreflang` 移除。
- 已发布 URL 按站点策略返回 404、410 或跳转回退语言。
- 不删除内容、版本和模板绑定历史。
- 停用必须显示受影响页面数量。

### 9.6 验收标准

- 后台可以新增任意符合规则的语言，无需改核心代码。
- 同一站点可以为英语和德语绑定完全不同的模板套装。
- RTL 语言启用后后台数据和前台模板不会破坏布局。

## 10. 内容管理页面

### 10.1 内容列表

顶部指标：内容组总数、待审核、已发布、需要更新、回收站。

筛选：站点、Locale、内容类型、状态、负责人、更新时间、AI 状态、SEO 问题、是否有缺失语言版本。

搜索：标题、Slug、内容 ID、核心关键词。正文全文搜索由搜索索引完成。

列表字段：标题、内容类型、站点、语言、负责人、状态、AI 状态、SEO 状态、更新时间、计划发布时间。

行级操作：列表直接显示编辑、查看和删除；查看使用安全只读预览，删除将整个内容组及其全部语言版本软删除到回收站。详细工作台继续支持复制、添加语言版本、提交审核、发布和查看版本。列表支持逐行选择、全选当前筛选结果、批量改状态、批量改栏目和批量移到回收站，并在确认前显示影响数量。批量修改最多同步处理 100 个 Locale，任一冲突整批回滚。

批量操作：分配负责人、修改状态、发起本土化、创建发布、导出、移到回收站。

### 10.2 内容编辑器布局

编辑器建议采用以下标签或分区：

- **正文**：标题、摘要、正文、栏目、标签和媒体；
- **SEO**：H1、SEO 标题、描述、关键词、Canonical、Robots、OG、JSON-LD；
- **语言版本**：同一内容组下各站点/Locale 状态；
- **发布设置**：状态、计划发布时间、发布范围和预览；
- **版本历史**：修订快照、操作者、时间和差异；
- **审计**：与该内容相关的操作记录。

### 10.2.1 单页面二级栏目

内容管理必须提供深链接二级栏目：

- `#/admin/content?section=articles`：文章管理；
- `#/admin/content?section=pages`：单页面管理，只显示 `content_type=page` 的内容 Locale；
- `#/admin/content?section=pages&editor=create&content_type=page`：新建单页面。

单页面管理用于“关于我们、联系我们、专题页面、服务页面和自定义页面”。它们是多个独立内容实例，共用一个单页面模板，不允许把“新建页面”误实现为在服务器中新建任意模板文件。页面列表复用真实的搜索、状态筛选、选择、批量改状态、批量改栏目、编辑、前台查看和软删除能力；所有操作继续按站点/Locale RBAC 范围校验。

新建页提供“单页面模板”选择。关于我们（`page/about`）、联系我们（`page/contact`）、专题（`page/landing`）、服务（`page/service`）和自定义空白页（`page/custom`）会填入可继续修改的标题、建议 Slug、栏目、页面布局、模板 Key 和默认 `noindex` 策略；模板决定前台页面结构与所需资源。预设不发布内容、不创建模板文件，也不覆盖用户已经保存的页面。

选择“联系我们”模板并保存时，服务端必须在同一事务中自动创建并绑定默认安全询盘表单，包含联系人、邮箱、电话、需求说明和隐私同意字段；字段、提交按钮和成功信息按页面 Locale 使用对应语言。后台默认只显示“查看询盘”，将字段修改收纳为“高级字段设置”，不把拖拽搭建放进单页面的日常创建流程。新建成功后跳回“内容管理 → 单页面”列表。

### 10.2.2 单页面 SEO 与模板职责

- 单页面继续拥有独立 H1、Title、关键词、Description、Canonical、OG、JSON-LD、封面、正文、版本和发布状态；JSON-LD 默认适用 `WebPage`。
- `content_type=page` 新建时默认输出 `noindex,follow`，并默认不进入 Sitemap。后台可在页面编辑器明确选择“允许收录”；企业介绍、服务和专题页经 SEO 审核后可进入 Sitemap，联系、隐私和提交成功页建议保持 `noindex,follow`。
- 模板工作区的 `pages/page.html` 下提供“管理页面”和“新建页面”入口。前者进入页面列表，后者进入页面编辑器；该模板文件只决定公共视觉结构，不能承载某一页的具体正文。
- 页面发布后使用所属站点端口/域名和自身 Slug 打开真实前台；未发布页面只允许经过认证的安全预览，不能泄漏给公开路由。

### 10.3 基础字段

| 字段 | 规则 |
|---|---|
| 内容类型 | 文章、页面、落地页、栏目、产品；支持扩展 |
| 标题 | 2–200 字符 |
| Slug | 小写字母、数字、连字符和路径分隔符，站点/Locale 内唯一 |
| 摘要 | 最大 500 字符 |
| 正文 HTML | 最大 2 MiB，服务端白名单清洗 |
| 站点 | 创建后不能直接迁移，迁移走专用任务 |
| Locale | 必须是站点已启用 Locale |
| 负责人 | 必须拥有目标站点/Locale 权限 |
| 状态 | 草稿、待审核、已发布、需要更新、已归档 |

未来 `scheduled_at` 与“发布”组合时，列表显示“定时发布”；到点前公开详情、列表、`hreflang` 和发布页面计数必须排除该版本。当前第一阶段使用服务端时间门自动开放，持久化调度任务、通知和重试在任务中心阶段实现。

### 10.4 编辑体验

- 自动保存只保存到草稿版本，不自动发布。
- 本地恢复草稿不得包含密码、Token 或敏感配置。
- 离开未保存页面时提示。
- 支持标题、Slug、摘要和 SEO 字段字数提示。
- 支持桌面、平板和手机宽度预览。
- 预览使用一次性短期令牌，不把草稿公开给搜索引擎。

### 10.5 富文本安全

- 禁止脚本、事件属性、iframe、危险 URL 协议和内联可执行内容。
- 粘贴内容先在前端清理，保存时服务端必须再次清理。
- 图片只引用媒体中心已通过扫描的资源。
- 嵌入内容必须来自允许列表。
- 原始 HTML 模式需要单独权限并记录审计。

### 10.6 内容状态流

```text
草稿 → 待审核 → 已发布 → 需要更新 → 待审核
  ↑       ↓          ↓
  └── 退回修改     归档/撤回
```

- 作者不能审核自己的内容时，系统支持职责分离开关。
- 退回必须填写原因。
- 发布前生成不可变修订快照。
- 撤回已发布内容必须选择 404、410 或重定向策略。

### 10.7 多语言内容组

- 同一 `content_id` 下，每个站点/Locale 保存独立正文和 SEO。
- 添加语言版本时只复制结构和人工允许继承的字段。
- 不得把源语言正文自动当作目标语言正式内容。
- 每个语言版本独立审核、发布、回滚和锁定字段。

### 10.8 版本历史

版本列表字段：版本号、动作、状态、操作者、更新时间、发布关联 ID。

支持：查看快照、字段级差异、恢复为新草稿、复制某个字段。恢复不能覆盖当前版本，必须生成新版本。

### 10.9 验收标准

- 两名编辑同时修改同一版本时，后保存者收到冲突提示且输入不丢失。
- 无 SEO 权限的编辑修改正文时，原 SEO 字段保持不变。
- 恶意 HTML 保存后不可执行。
- 软删除内容可在回收站恢复，并保留修订和审计。

## 11. 模板管理页面

### 11.1 模板列表

指标：模板套装数、当前生效、待检查、历史版本、存在安全问题。

筛选：状态、支持语言、绑定站点、版本、完整度、上传者。

列表字段：模板名称、包标识、版本、支持语言、页面完整度、绑定数量、安全状态、当前状态、更新时间。

模板名称、整行空白区域或“编辑”按钮均可展开当前模板；操作按钮本身不应误触发行展开。一次只展开一个工作区，展开按钮使用 `aria-expanded` 和 `aria-controls` 表达状态。

### 11.2 安装模板

上传流程：

1. 校验文件大小和压缩包格式。
2. 防 Zip Slip、符号链接和压缩炸弹。
3. 杀毒扫描。
4. 读取并严格校验模板清单。
5. 检查禁止文件类型和可执行文件。
6. 编译/解析所有模板。
7. 检查必需页面和静态资源。
8. 生成候选版本，不能直接覆盖生效版本。

模板清单至少包含：包 ID、名称、版本、兼容 CMS 版本、页面模板列表、资源清单、可配置项、支持语言和校验和。

### 11.3 模板详情

标签页：概览、页面模板、资源、配置项、语言词典、站点绑定、版本历史、安全报告。

页面完整度检查：首页、列表、详情、栏目、搜索、404、维护页、Sitemap/robots 输出支持。

### 11.4 站点/语言绑定

绑定键为 `site_id + language_id/locale`。同一站点不同语言可以绑定不同模板包和版本。

绑定流程：

1. 选择站点和语言。
2. 选择候选模板版本。
3. 检查必需页面、词典和配置。
4. 在对应 localhost 站点端口生成完整预览。
5. 人工确认。
6. 创建模板发布任务。
7. 原子切换并保留旧版本用于回滚。

### 11.5 模板编辑

模板行下方提供紧凑的三栏编辑工作区：

- 左侧文件导航按“公共结构、页面模板、系统页面”分组；
- 公共结构包含头部和尾部；
- 页面模板包含首页、栏目页、内容页和单页面；
- 系统页面包含搜索页和 404；
- 中间为带行号的源码编辑器、文件名、版本、字节数、行数、撤销、校验和保存操作；
- 右侧展示校验结果、允许的数据变量、修改说明、修订次数和安全草稿说明；
- 支持 `Ctrl/⌘ + S` 保存；小屏把文件导航改成横向可滚动分组，检查面板移动到编辑器下方。

在线源码编辑必须满足：

- 请求只提交清单内的受控 `file_key`，不得提交或解析任意磁盘路径；
- 文件名、类型和所属模板由数据库记录决定；
- 单文件不超过 2 MiB，必须为 UTF-8；
- HTML 拒绝脚本、活动标签、事件属性、内联样式、危险 URL 和递归模板定义；
- 保存前使用 `missingkey=error` 重新解析 Go HTML 模板；
- 保存使用版本号乐观锁；冲突和校验失败必须保留浏览器中的输入；
- 每次成功保存创建不可变修订并写入操作者、修改说明、字节数和审计日志；
- 保存只产生候选草稿，不能直接替换当前在线模板；正式切换仍走完整预览、发布与原子回滚流程。

### 11.6 验收标准

- 上传包含 `../`、符号链接或可执行文件的模板必须拒绝。
- 英语和德语可在同一站点分别绑定不同模板。
- 新模板发布失败时旧模板继续服务。
- 模板回滚不修改内容数据。
- 路径穿越形式的文件键、危险 HTML 和过期版本保存请求必须拒绝。
- 点击模板行能展开，点击详情/预览不会误触发展开；键盘可访问所有文件和操作。

## 12. SEO 中心页面

### 12.1 SEO 总览

指标：健康页面比例、严重问题、警告、优化建议、关键词计划数、Sitemap 状态。

支持按站点、国家市场、Locale、内容类型、问题级别和检查时间筛选。

### 12.2 问题列表

检查项至少包括：

- 标题缺失、过短、过长或重复；
- Meta Description 缺失、重复或长度异常；
- H1 缺失或多个 H1；
- Canonical 缺失、跨站错误或指向不可访问 URL；
- `hreflang` 缺失、错误或双向关系不完整；
- Robots 与页面发布状态冲突；
- Sitemap 缺页、死链或包含 noindex 页面；
- 404、重定向链和循环；
- 图片 Alt 缺失；
- JSON-LD 无效或与页面内容不一致；
- 页面没有内部链接或层级过深；
- Slug 冲突和非规范 URL。

列表字段：检查项、站点/Locale、严重度、受影响页面、首次发现、最后检查、状态、负责人。

操作：查看受影响页面、批量分配、忽略并填写理由、标记已修复、重新检查。

### 12.3 关键词规划

字段：目标站点、国家市场、Locale、搜索意图、核心关键词、次要关键词、内容类型、目标 URL、来源、状态、负责人。

AI 只能提出建议；人工锁定关键词不得被自动覆盖。不同国家/Locale 必须独立维护，不得共享一份机械翻译关键词表。

### 12.4 Sitemap 与 robots

每个未停用站点独立展示：

- 本地 Sitemap 地址和正式域名 Sitemap 地址；
- 可收录内容 URL 数、可渲染语言数和最后更新时间；
- 自动排除的单页面（`content_type=page`）数量；
- robots.txt 地址、当前自动规则和本地预览；
- 站点地图生成状态、模板绑定状态和读取错误；
- Search Console 提交状态，P1。

Sitemap 与 robots 当前由服务端按站点实时生成，不单独维护 URL 副本；新增站点后只要启用语言并绑定可渲染模板，就会自动出现对应机器文件。生产 robots 默认允许公开页面并屏蔽后台、API、登录、安装、预览和账户路径；本地端口 robots 固定 `Disallow: /`。修改 robots.txt 必须校验是否意外屏蔽全部生产站，并进行高风险确认。

单页面新建时采用页面级 `noindex,follow`（同时输出 Meta Robots 与 `X-Robots-Tag`），并默认从 Sitemap 排除；允许收录的企业介绍、服务和专题页会输出 `index,follow` 并进入 Sitemap。无论哪种策略，都不使用 `robots.txt Disallow` 屏蔽单页面，避免搜索引擎无法读取页面 robots 指令。

### 12.5 结构化数据

支持站点默认 Schema 和页面级覆盖。保存时校验 JSON 对象、大小、必填字段和 URL。预览必须显示最终合并结果，不能只显示输入片段。

### 12.6 SEO 检查任务

可选择全站、指定 Locale、内容类型或 URL 集合。大型检查进入任务中心，支持增量检查和断点续跑。

### 12.7 验收标准

- 每个语言版本可以保存完全不同的标题、描述和关键词。
- SEO 检查不读取用户无权访问的站点数据。
- noindex 页面不会进入 Sitemap。
- `hreflang` 输出包含自引用和双向关系。

## 13. AI 本土化页面

### 13.1 强制定位

本模块不是翻译器。系统根据源内容的事实、目标国家的搜索习惯、用户意图、专业术语和品牌语气重新创作目标语言内容。

AI 不得虚构价格、时效、服务范围、认证、法律承诺、客户案例或产品能力。

### 13.2 任务列表

指标：处理中、待审核、本月完成、失败、人工锁定字段数和本月成本。

筛选：源站点、目标站点、目标 Locale、任务状态、同步模式、创建人、模型提供方和时间。

列表字段：源内容、目标市场/Locale、同步模式、模型、进度、成本、状态、创建时间、更新时间。

### 13.3 发起任务

字段：

- 源内容和源版本；
- 目标站点、国家市场和 Locale；
- 同步模式；
- 目标受众；
- 搜索意图；
- 品牌语气；
- 必须保留事实；
- 禁止改写字段；
- 目标关键词或关键词研究任务；
- 模型、温度、最大成本和超时；
- 生成后是否自动进入人工审核。

目标分站使用“上线状态驱动”而不是固定语言清单：后台读取所有运行中的分站，只把已启用 Locale、已绑定且可安全渲染模板、当前用户有内容与 SEO 权限、尚无目标版本的项目默认选中。维护站、停用站、停用 Locale、未绑定或不可渲染模板必须禁用并说明原因。以后新增语言及模板完成上线后，自动进入该列表，不修改前端代码。

同步模式：

- 全页面本土化；
- 只处理变更块；
- 只重写标题与 SEO；
- 只生成关键词建议；
- 从结构创建空白目标草稿。

### 13.4 生成字段

AI 可生成：标题、H1、摘要、正文、CTA、FAQ、Slug 建议、SEO 标题、Meta Description、核心与次要关键词、OG 文案、图片 Alt 建议和结构化数据建议。

站点、Locale、模板、事实锁定字段、法律文本和人工锁定 SEO 字段不得自动覆盖。

### 13.5 审核工作台

采用源版本、AI 候选版本和当前目标版本三栏或字段级对比。

审核员可以：

- 逐字段接受或拒绝；
- 手工编辑候选；
- 锁定字段；
- 查看关键词与内容的对应关系；
- 查看生成依据、模型和 Token/成本；
- 退回重新生成并填写原因；
- 批准为目标语言草稿。

AI 结果不能直接发布；第一版必须经过人工审核。

### 13.6 状态流

```text
排队 → 分析源内容 → 关键词研究 → 生成 → 质量检查 → 待人工审核
                                                   ↓
                                          批准草稿 / 退回 / 失败
```

每一步保存输入版本、输出摘要、模型、提示模板版本和错误信息，确保可追溯。

### 13.7 质量检查

- 目标语言检测；
- 事实一致性；
- 禁止声明检查；
- 关键词堆砌检查；
- 标题和描述长度；
- HTML 结构与链接安全；
- 与现有页面重复度；
- 品牌术语和禁用词；
- JSON-LD 合法性。

### 13.8 验收标准

- 德语和法语任务可以根据各自市场生成不同关键词与页面结构。
- 源内容更新后可只重写发生变化的语义块。
- 人工锁定字段在重新生成后保持不变。
- 任务失败不会覆盖现有目标语言内容。

## 14. URL 与伪静态页面

### 14.1 页面组成

- URL 规则；
- 重定向；
- Slug 冲突；
- 历史 URL；
- 404/410 记录；
- URL 测试工具。

### 14.2 URL 规则

按站点和内容类型配置：路径前缀、语言前缀、Slug、日期/栏目段、伪静态后缀、尾斜杠和大小写规则。

规则编辑时必须显示示例 URL，并对现有 URL 执行影响预估。

### 14.3 重定向列表

字段：来源路径、目标 URL、站点、Locale、状态码、匹配类型、优先级、命中次数、最后命中、状态。

支持状态码：301、302、307、308、410。

来源支持精确路径和受限参数匹配；正则规则仅允许高级权限用户创建，并限制复杂度，防止 ReDoS。

### 14.4 安全规则

- 禁止重定向到 `javascript:`、`data:` 等危险协议。
- 外部目标必须明确标记并二次确认。
- 禁止循环和超过配置长度的重定向链。
- 规则按确定性优先级执行，并提供命中解释。

### 14.5 URL 测试工具

### 14.6 验收标准

- 已发布 Slug 修改时自动生成旧 URL 到新 URL 的重定向建议。
- 不允许不同内容占用相同站点/Locale/Slug。
- 重定向循环在保存前被拒绝。

## 15. 媒体中心页面

### 15.1 媒体列表

视图：网格和表格切换。

指标：媒体数量、存储用量、待处理、缺少 Alt、孤立文件、本月优化空间。

筛选：站点、类型、上传人、扫描状态、Alt 状态、引用状态、日期、文件大小。

字段：缩略图、文件名、类型、原始大小、优化后大小、尺寸、引用次数、扫描状态、上传时间。

### 15.2 上传流程

1. 浏览器选择或拖放文件。
2. 校验扩展名、MIME、大小和数量。
3. 上传到隔离区。
4. 服务端识别真实文件类型。
5. 杀毒和内容安全扫描。
6. 图片解码重编码，移除危险元数据。
7. 生成 WebP/AVIF 和响应式尺寸。
8. 保存校验和并执行重复文件检测。
9. 扫描通过后进入可用状态。

扫描完成前不可插入正文或公开访问。

### 15.3 媒体详情

字段：标题、文件名、Alt、说明、版权、来源、站点范围、焦点位置、原图和衍生图、引用列表、技术元数据。

Alt 文本按 Locale 独立保存；AI 可以建议，但必须人工确认。

### 15.4 删除规则

- 有引用的媒体默认禁止删除，先显示引用页面。
- 无引用媒体进入回收站并延迟物理清理。
- 强制替换需要选择新媒体并创建内容修订。
- 删除、恢复和替换写审计日志。

### 15.5 验收标准

- 伪造扩展名、超大图片、SVG 脚本和恶意压缩文件不能进入公开存储。
- 相同文件可通过校验和提示复用。
- 删除被引用文件不会产生静默断图。

- 单页增量发布不会重建无关站点和语言。

### 20.6 AI 提供方

系统设置下设置“AI 配置”二级栏目，作为多个 AI 接口和模型的统一配置库，不允许各业务页面重复保存 API Key。中央页面不展示 SEO、本土化等用途分配；具体 AI 功能开发时再在该功能内部选择或调用已启用配置。

第一阶段已实现：

- 新增、编辑、启停、删除和连接测试多个 OpenAI Chat Completions 兼容提供方；
- 配置名称、服务商预设、API 根地址、默认模型、API Key、请求超时和启用状态；
- 预设 OpenAI、DeepSeek、Google Gemini 兼容接口、Qwen、SiliconFlow、OpenRouter、Groq、xAI、Mistral、Moonshot、智谱、Ollama、LM Studio 和自定义兼容接口；
- 默认模型提供常见模型建议，但允许直接填写服务商给出的任意模型 ID；
- 配置保存后立即生效，不需要重启服务；环境变量只作为最后一级兼容回退；
- 使用版本号保护多人同时修改，冲突时返回提示并要求刷新；
- `system.view` 可以查看脱敏状态，只有 `system.manage` 可以修改和测试。

后续扩展：并发限制、月度预算、单任务上限、Token/费用统计、提示词版本和提供方内容保留策略。

API Key 使用主密钥派生的 AES-GCM 密钥加密保存。页面和 API 只显示是否已配置及末四位，不回显完整密钥或数据库密文；远程接口必须使用 HTTPS，本机模型才允许使用 localhost HTTP 和空密钥。

内容类 AI 功能仍应在各自流程中定义人工审核、覆盖和发布规则。提供方变更、连接测试和调用失败均写入不可变审计日志。

### 20.7 日志与监控

显示版本、启动时间、Go 版本、数据库状态、Redis、队列、磁盘、内存、Goroutine、最近错误和健康检查。

### 20.8 生命周期与升级

- 各标签页独立保存。
- 修改前后显示差异。
- 环境变量管理的只读配置明确标记，不能假装保存成功。

## 21. 公开站点、本地预览和域名路由

### 21.1 请求匹配顺序

1. 独立 localhost 监听器直接绑定站点。
2. 生产请求按规范化 Host 查询 `site_domains`。
3. 别名根据策略直接服务或 308 跳转主域名。
4. 读取该独立站点绑定的 Locale；单语言站不在 URL 中重复 Locale。
5. 按伪静态规则匹配内容。
6. 找不到内容时执行重定向、410 或 404。

### 21.2 本地预览

- 首批六种语言各自作为独立站点和独立端口：英语 `8081`、德语 `8082`、法语 `8083`、西班牙语 `8084`、意大利语 `8085`、荷兰语 `8086`。
- 单语言站直接使用端口根路径和干净 Slug，例如意大利文章为 `http://localhost:8085/guide/spedizioni-internazionali`，不得生成 `/it-IT/` 二级目录。
- 语言切换跳转到另一个站点端口；生产环境改为跳转到该站绑定的独立正式域名。
- 预览使用与生产相同的模板和 URL 生成逻辑。
- 所有预览页面 noindex，草稿预览使用短期签名令牌。

### 21.3 正式站点

- 输出完整 HTML、Canonical、hreflang、Open Graph、JSON-LD 和正确状态码。
- 维护状态返回 503 和 `Retry-After`。
- 已发布页面允许公共缓存；后台和预览禁止缓存。
- Host 未绑定时不得错误展示其他站点内容。

## 22. API 与后端开发约定

### 22.1 接口格式

- 基础路径 `/api/v1`。
- 成功返回对象或带明确复数键的列表对象。
- 列表返回 `items/total/limit/offset` 或模块约定的等价字段。
- 错误返回稳定错误代码、中文消息、字段错误和请求 ID。
- 未知 JSON 字段返回 400。

### 22.2 HTTP 状态码

| 状态码 | 用途 |
|---|---|
| 200 | 查询或更新成功 |
| 201 | 创建成功 |
| 202 | 异步任务已接受 |
| 204 | 无响应体成功 |
| 400 | JSON 或请求格式错误 |
| 401 | 未登录或会话失效 |
| 403 | 权限、范围、CSRF 或 Origin 不通过 |
| 404 | 对象不存在或为防越权隐藏存在性 |
| 409 | 唯一冲突或乐观锁冲突 |
| 413 | 请求体或文件过大 |
| 422 | 字段业务校验失败 |
| 429 | 限流 |
| 500 | 未预期内部错误 |
| 503 | 维护或关键依赖不可用 |

### 22.3 缓存失效

站点、语言、模板、URL、SEO 或内容写入后，只失效受影响的站点/Locale/页面缓存。全量清缓存必须是明确的运维动作。

### 22.4 审计事件命名

使用 `对象.动作`，例如：

- `site.created`；
- `site.domain_updated`；
- `content.reviewed`；
- `content.published`；
- `template.activated`；
- `localization.approved`；
- `publish.rolled_back`；
- `security.user_unlocked`；
- `settings.security_updated`。

## 23. 非功能需求

### 23.1 性能

- 后台普通列表 P95 小于 500 毫秒。
- 单记录保存 P95 小于 800 毫秒，不含异步任务执行时间。
- 控制台聚合接口 P95 小于 500 毫秒。
- 公开缓存页面首字节 P95 小于 200 毫秒，目标环境内测量。
- 10 万、100 万和 1000 万内容规模分别执行索引和分页压测。
- 大导入、全站发布、SEO 全站检查和 AI 批量任务全部异步。

### 23.2 安全

- Argon2id、MFA、会话轮换、CSRF、Origin、RBAC、站点/Locale 范围和审计必须默认启用。
- 文件、模板、富文本和 URL 接受服务端白名单校验。
- 所有外部 HTTP 请求防 SSRF，限制协议、目标、DNS 重绑定、响应大小和超时。
- Redis 生产环境使用 ACL、TLS 和独立账号。
- 备份加密，密钥与备份文件分离。
- CI 执行 `govulncheck`、单元测试、集成测试和可用环境下的竞态检测。

### 23.3 可访问性

- 达到 WCAG 2.2 AA 文字对比度。
- 所有功能支持键盘操作和可见焦点。
- 状态不能只依赖颜色。
- 表单错误与字段建立程序化关联。
- 对话框管理焦点并支持 Escape；高风险未保存表单不能被误关闭。
- 支持 200% 缩放、长中文/德文文本和 RTL。

### 23.4 响应式

- 1440px 以上：完整侧栏和高密度表格。
- 960–1439px：侧栏可折叠，表格保留水平滚动。
- 720–959px：抽屉导航，表单单列或双列自适应。
- 720px 以下：支持审批、查看状态和基础编辑；复杂模板/SEO 工作台提示使用桌面端获得完整体验。

## 25. 推荐开发顺序

### 阶段 A：可用的安全骨架

登录/MFA、RBAC、审计、公共布局、站点、语言、内容基础 CRUD、localhost 独立端口和正式域名。

### 阶段 B：可发布的多语言网站

模板安全上传、站点/语言模板绑定、URL、SEO、媒体、原生 HTML 前台和增量发布。

#### 当前原生前台基线（2026-08-27）

- 已提供英语、德语、法语、西班牙语、意大利语和荷兰语六套本地化首页文案与导航；后台仍保持中文。
- 首页包含语言切换、服务介绍、物流路线视觉、已发布内容列表、联系入口和完整页脚；文章使用独立详情版式。
- 公开内容查询只返回 `published` 状态、未软删除、站点语言已启用的数据；草稿、待审核、需要更新和归档内容统一返回 404。
- 独立单语言站支持 `/{multi/level/slug}` 多级伪静态路径，不带 Locale 目录；只有未来明确配置为站内多语言的站点才使用 `/{locale}/{slug}` 兼容模式。
- 公开页面由 Go 服务端输出完整原生 HTML，并输出 `lang`、Title、Description、Canonical、hreflang、Open Graph、robots 和安全序列化 JSON-LD。
- 本地预览始终设置 `noindex,nofollow`、`X-Robots-Tag` 和 `no-store`，不输出 Canonical；后台、API、登录和媒体管理路径不会从预览端口透出。
- 后台已发布内容的查看弹窗和编辑页提供“打开前台页面”；未发布内容只显示后台沙箱预览。

### 阶段 C：可靠运营

任务中心、回滚、缓存、备份、监控、通知、批量操作和大数据压测。

### 阶段 D：AI 本土化

提供方适配、关键词研究、语境重写、字段锁定、差异审核、质量检查、成本控制和版本审计。

## 26. 单模块完成定义

一个页面模块只有同时满足以下条件才算完成：

- 页面、接口和数据库字段已实现；
- 权限和数据范围在后端生效；
- 创建、读取、更新、停用/归档流程完整；
- 加载、空、失败、冲突和无权限状态完整；
- 关键动作写审计；
- 缓存失效和异步任务规则正确；
- 单元、集成和页面测试通过；
- 无已知高危漏洞；
- 开发文档、接口文档和运维说明已更新；
- 在真实浏览器完成桌面和移动宽度人工验收。
