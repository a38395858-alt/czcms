# 运费与时效查询：本地多国家版

当前实现保存在本地，没有部署到线上。所有费用、时效、仓库与服务均为演示配置，不代表实时运价、仓库可用性或交期承诺；页面明确提示联系确认具体报价及时效。

## 页面与入口

本地端口为 8180，各站支持以下前缀：

| 国家 | 站点前缀 | 查询语言 | 币种 |
| --- | --- | --- | --- |
| 美国 | /preview/global | 英语 | USD |
| 德国 | /preview/germany | 德语 | EUR |
| 法国 | /preview/france | 法语 | EUR |
| 西班牙 | /preview/spain | 西班牙语 | EUR |
| 意大利 | /preview/italy | 意大利语 | EUR |
| 荷兰 | /preview/netherlands | 荷兰语 | EUR |

各站独立查询页为“前缀/tools/shipping-calculator”，结果页为“前缀/tools/shipping-results”。旧的一级查询、结果地址永久跳转并保留参数。

美国及五个欧洲站首页在主视觉之后展示完整查询表单，使用 H2；独立功能页使用 H1 和面包屑。首页及功能页的页脚提供入口，顶部导航不添加工具菜单。美国站使用英语、美国目的地和 USD 参考报价。

首页查询区与独立功能页共用 Go 模板。德国、法国、西班牙、意大利、荷兰的 React 首页通过同一份服务器 HTML 进行预渲染和 hydration；脚本对每个表单只初始化一次。

## 国家数据

欧洲五站各有 20 个中国起运地、7 个本国目的城市、140 组国际演示线路和 140 组整柜线路，以及 7 个本国仓库和 7 组明确的仓库—邮编配送线路。各国独立数据位于 frontend/assets/data/shipping-planner.{de,fr,es,it,nl}.demo.json。

文件包括币种、语言、邮编规则、目的地区域、参考海港、仓库、LCL/FCL/空运/快递与尾程费率、时效、界面翻译、SEO 元数据和当地说明内容。各国费率和时效分别配置。未配置的路线、服务或邮编组合显示无样例报价，不套用邻近城市价格。欧洲站不提供美森或美国仓库。

美国原目录 shipping-planner.demo.json 保留 20 个起运地、7 个目的城市、140 组国际及整柜线路、22 个仓库和 24 组尾程邮编线路。

## 计费及查询行为

- LCL：max(CBM, kg / 1000, 1) 乘以每 W/M 运价。
- FCL：柜型为 20GP、40GP、40HQ/40HC，总价为每柜费率乘柜数。纯海运整柜隐藏、禁用并忽略重量体积，新链接不携带这两个字段。
- 空运：体积重除数 6000，最低 45 kg，按 1 kg 向上取整。
- 国际快递：体积重除数 5000，最低 0.5 kg，按 0.5 kg 向上取整。
- 尾程：本国仓库到收货邮编，包裹按计费重、卡车按整数托盘数计价。两项为独立选择，不相加。
- 德、法、西、意、美使用五位邮编并保留前导零；荷兰使用四位数字加两字母，可将 3011aa 规范为 3011 AA。
- FCL 范围为港到港，内陆城市对应参考海港；内陆派送另行确认。其他国际演示为门到门参考，尾程为仓库到地址。
- 国际时效按发运后的自然日，尾程按工作日。税费、保险、特殊附加费、备货和订舱时间等不在演示金额与时效内。

查询跳转至本站结果页并由该国目录重新计算；刷新及返回保留选择。询价入口返回本站询盘区并保留条件，支持预填且不覆盖客户已填写文字。校验错误、空结果、加载失败与重试提示使用当地语言。

## SEO

各站首页与独立查询页有不同的 title、description、keywords、Open Graph 和 Twitter 元数据。当地目的地区域、参考海港、上海起运的 LCL 单位费率及时效样例、进口与派送说明、FAQ 均由服务器输出，支持不执行 JavaScript 的抓取。

德国采用区域索引加运输说明；法国先说明海港及运输选择；西班牙采用区域分组；意大利先展示计费与配送说明；荷兰采用目的地区域与海港对照布局。FAQ 结构化数据与可见问题保持一致。Keywords 仅作元数据维护，不承诺排名效果。

各站 sitemap 只加入无参数的 /tools/shipping-calculator，结果页不收录并设为 noindex。本地预览维持 noindex；正式查询页使用本国规范地址。

## 启动与验证

在项目根目录运行 scripts/start-shipping-planner-preview.ps1 -Restart。修改 React 首页源码后需先在 frontend/reference-template 和 frontend/reference-template-nl 执行 npm run build，再重启 Go 预览，将模板、脚本、预渲染页面与目录嵌入可执行文件。脚本入口、模型依赖和样式版本需同步更新。

自动化检查：node --test frontend/tests/*.test.mjs；go test ./internal/app ./internal/httpserver。两个 React 工程还可执行 npm run typecheck。

回归覆盖国家隔离、费用和时效、邮编与仓库精确匹配、FCL 柜数计费、跨页恢复、SEO、站点路由和 sitemap。浏览器验证覆盖五站首页、独立工具、结果跳转和 1440/390 宽度。
