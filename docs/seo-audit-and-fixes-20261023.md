# 2026-10-23 六语整站 SEO 检查与修复

范围：英语主站及德语、法语、西班牙语、意大利语、荷兰语独立端口站点。当前仍为上线准备阶段，保留禁止抓取与禁止收录设置。

## 已实施的修复

- 六语 About、服务目录、行业目录、联系页分别使用与页面用途相符的标题和摘要，避免首页和目录共用摘要；About 正文保留经营者资料。
- 资料页的语言别名、旧 `ProductService` 地址和文章列表别名永久跳转到当前语言的标准路径。编辑人员已发布的自定义资料页仍优先。
- 修正文章列表和资料页 JSON-LD 中的空地址、首页地址和相对地址；About 使用 AboutPage，联系页使用 ContactPage，目录使用 CollectionPage。
- 修正有文章的列表页丢失当前页面包屑的问题；文化页增加 About 父级。
- 专题 JSON-LD 增加稳定的页面、网站、组织、服务、FAQ 和面包屑标识及其关系。
- 补齐分享图片、图片说明、页面地址和 Twitter 信息。预览站的分享地址使用当前端口，不依赖 canonical 是否启用。
- 修正前端加载后把多语首页 SEO 信息覆盖为旧模板域名或语言目录的问题，由服务端按当前访问站点提供信息。
- 文章默认以经营组织作为发布方，不把后台账号直接标成已核验的个人作者；页面展示发布方并链接到 About。编辑人员明确填写的个人作者结构化数据仍保留。
- 六语文章页增加规划说明：时效、运价与成本为规划示例，实际要求和报价需在订舱前确认。
- 超出文章列表页数的分页返回真实 404。第二页及以后使用自身分页地址与标题；筛选结果禁止收录，分页和筛选不错误关联其他语言的第一页。
- 文章列表三张展示配图改用 WebP，总体积从 9,223,905 字节降为 381,598 字节（约减少 95.9%），减轻首次加载负担；原始 PNG 保留备份。该优化不代表已经通过真实用户 Core Web Vitals 评估。
- 德语首页首屏图从 2,723,467 字节降为 216,386 字节（约减少 92.1%）。补查本轮抓取页面 `<img src>` 引用的本地静态图片，原本超过 500 KB 的图片均已改用压缩版本；用户上传媒体保留原始数据。

## 发布与验证

发布信息与公网复核结果见 [部署记录](deployment-ubuntu-ip.md)。本轮只发布程序与内嵌前端资源，没有用本地数据库覆盖线上内容。

验证包含 Go 测试、前端类型检查和生产构建、整站 sitemap 抓取、内链及锚点检查、分享图片与页面图片可用性、结构化数据 URL、六语桌面与手机浏览器检查。浏览器检查覆盖脚本执行后的页面，避免只看服务端 HTML 漏掉覆盖问题。

最终公网结果：153 个页面、80 个补充内链、231 个图片地址与 60 个浏览器场景通过。另有 24 项 robots / 404 / 永久跳转检查通过。四张 WebP 线上文件的类型、内容摘要与本地一致。这些是本次自动检查的覆盖范围，不等同于 Google 已收录或排名审计结果。

## E-E-A-T 仍需真实材料

程序和结构化数据不能代替实际经验与信誉证明。网站经营者名称和经营地址采用所有者提供的信息；英文名称为对外展示译名，地址没有被描述为已经核验的注册地。

1. 提供真实营业执照、许可或行业资质及可核验的编号、机构和有效期，再发布资质页。此前提供的图片包含空白模板，未作为真实资质上线。
2. 提供团队负责人、作者或审核人的真实履历、业务分工和授权照片，再建立团队档案与文章审核署名。
3. 提供获得客户授权的运输案例，包括货物、路线、难点、实际过程和可公开结果；隐去客户敏感资料。不要使用虚构评价或未经证实的数据。
4. 提供可公开的业务电话、邮箱和完整隐私、合同条款。SMTP 通知邮箱未直接视为获准公开的业务联系方式。
5. 企业文化 AI 图片继续作为理念配图，不能当作真实仓库、团队、设备或履约记录的证明。
6. 运费、时效、海关和平台规则类文章应由实际业务人员审核，注明来源、适用条件与真正的更新日期；新增规划说明不代表正文资料已全部获得独立核验。

## 正式开放搜索前

- 为六语站绑定正式域名与 HTTPS，把语言切换、canonical、hreflang、sitemap 和 JSON-LD 地址切换到真实域名；端口是临时展示方案。
- 经所有者确认后开放公开页面的 robots 抓取并移除对应站点的 noindex 和 Nginx 禁止收录响应头，后台和私有路径仍限制抓取。
- 同时复查 robots 对公开图片、媒体路径和 Googlebot-Image 的限制，避免允许页面却继续阻挡图片；当前未擅自开放这些规则。
- 使用真实域名验证 Google Search Console，提交 sitemap，检查网页索引及真实用户的 Core Web Vitals。现阶段无 Search Console 或真实访问数据，不能给出实际 Google 收录、排名或核心网页指标合格结论。

这些修改解决本轮检测到的技术与展示问题，不构成 Google 排名或富媒体展示保证。
