新建元字段

创建后字段会自动显示在绑定对象的编辑页面。

字段定义

先确定字段身份和类型；Key 发布后不可修改。

草稿
数字　⌄
Namespace + Key 会组成唯一标识：shipping.minimum_order

绑定对象

字段会出现在所选对象的编辑页；可同时绑定多个对象。

产品显示在“产品基础信息”字段组已绑定
产品栏目显示在栏目编辑页，可作为筛选条件可选
文章此字段不适用于文章内容未选择

校验与显示

限制输入范围并决定字段如何出现在后台和前端。
