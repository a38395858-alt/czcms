# 表单邮件转发

后台入口：**系统设置 → 邮件转发**（`#/admin/settings?section=smtp`），需要 `system.manage` 权限。

已预设 QQ 邮箱：SMTP `smtp.qq.com`、端口 `465`、`SSL/TLS`，发件账号、发件邮箱和收件邮箱均为 `38395858@qq.com`。首次安装默认关闭，避免缺少授权码时产生发送失败记录。

## 启用

1. 在 QQ 邮箱设置的账户或账号安全页面开启 SMTP 服务，取得 SMTP 授权码。
2. 在后台填写授权码并保存。授权码不是 QQ 登录密码；保存后留空表示保留原值。
3. 点击“发送测试邮件”，确认收件箱或垃圾邮件中收到测试邮件。
4. 勾选“启用邮件转发”并保存。

更换其他邮箱服务时，修改服务器、端口、账号和发件邮箱。支持 SSL/TLS 和必需 STARTTLS，验证服务器证书，支持 PLAIN / LOGIN 认证。

## 表单与发送记录

所有表单共用入库入口，包括六个语言站的首页询盘、专题询盘、联系页面和资源订阅。全局 SMTP 开启且表单 `notify_enabled=true` 时，提交记录和发送任务在同一 SQLite 事务中保存。内置表单默认开启通知；已有内置表单在迁移 38 时开启一次，此后保留管理员的选择。

发送任务记录收件地址快照；修改收件邮箱只影响之后的新提交。启用前的历史提交不会补发。关闭转发会暂停队列，重新启用后继续发送已排队的邮件。

后台单工作线程异步发送。每封邮件最多尝试 5 次，失败后依次等待 1、5、15、30 分钟；达到上限后显示“发送失败”，可手动重新发送。进程重启后保留队列，超过 2 分钟的发送租约可以恢复。SMTP 单次发送限时 30 秒，显式测试限时 25 秒。

邮件包含站点、语言、表单、来源页面、提交时间和全部字段。有效的访客邮箱作为 `Reply-To`，发件地址始终使用配置的发件邮箱。参考文件只包含已有表单提交的文件元数据，不会附加文件内容。

SMTP 接受 DATA 后标记已发送；这表示服务器接受邮件，不保证最终到达收件箱。SMTP 接受与本地状态更新之间进程异常退出时，恢复可能重复发送；重试沿用相同 Message-ID，供邮箱识别重复邮件。

## 安全与验证

授权码使用现有 Keyring / AES-GCM 加密入库，不在 API、发送队列或审计日志中回显。测试和修改需要登录、系统管理权限和 CSRF 校验；保存采用版本号防止覆盖其他管理员修改。SMTP 错误按连接、TLS、认证、发件、收件和传输阶段显示，不记录服务器返回的原始认证内容。

测试覆盖：密码加密与保留、并发版本、表单通知开关、重复提交、队列事务回滚、持久化恢复、租约与并发领取、退避重试、暂停恢复、权限与 CSRF、两种 TLS 模式及 PLAIN / LOGIN、中文 MIME 和回复地址、证书验证。自动测试仅使用本地假 SMTP 服务。
