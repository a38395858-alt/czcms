# 网站内容发布操作手册

适用网站：<https://170.106.116.93/>

核对日期：2026 年 10 月 22 日。站点表已与线上数据库核对，操作说明按当前已部署代码编写。

## 1. 先记住：到底发到哪里

**发布位置由编辑页右侧“站点与语言”中的“目标站点 + 内容语言”决定。URL 路径决定这篇内容在该站点的具体地址。**

例如，目标站点选 `Global Route English`、语言选 `en`、URL 路径填 `guides/my-shipping-guide`，发布后的地址就是：

<https://170.106.116.93/guides/my-shipping-guide>

这是地址演示，不表示已创建该文章。

普通的“立即发布”保存并开放当前站点、当前语言的这一份内容版本，不会自动把文章分发给百度、Google 或其他外部网站，也不会自动生成所有语言站的版本。其他语言需要单独创建或通过“AI 同步其他语言”生成，再分别审核发布。

**顶部站点切换器和列表的“内容范围”主要帮助查看、筛选。不要只看顶部站点名称就点击发布，最终必须看编辑页右侧的目标站点和语言。**

## 4. 发布一篇新文章：推荐顺序

### 第一步：先写一张发布确认单

在动手前明确这四项。下面以英语主站为例：

| 确认项 | 示例 |
| --- | --- |
| 操作环境 | 线上，地址开头 `https://170.106.116.93/` |
| 目标站点 | `Global Route English`（global，ID 1） |
| 内容语言 | `en` |
| 发布后完整地址 | `https://170.106.116.93/guides/my-shipping-guide` |

如果要发德语站，目标站点必须改成 `FreightVanta Deutschland`，语言为 `de-DE`，查看地址使用 `/preview/germany/…`。

### 第二步：新建并确认站点

1. 进入“内容管理”，选择文章列表，点击新建按钮，进入“创建英语内容”页面。
2. **马上检查右侧“站点与语言 → 目标站点、内容语言”。当前新建编辑器默认选英语主站，即使你刚刚在顶部看的是其他站点，也要重新核对。**
3. 若直接创建其他语言内容，在首次保存前选择对应目标站点，再确认语言随之切换正确。
4. 现有内容进入编辑后，站点和语言通常锁定，不能用编辑该条记录的方式把它直接搬到别的站点。

### 第三步：填写内容并保存草稿

- 标题：这篇文章的名称。
- URL 路径：例如 `guides/my-shipping-guide`。只填路径，不填 `https://` 或域名。首选英文小写、数字和连字符。
- 正文：输入文章内容，插入所需图片。
- 摘要、栏目、标签：按文章内容填写。
- SEO 标题、Meta Description：填写与正文相符的描述；当前编辑器提交审核或发布时会检查 Meta Description。
- 封面图：建议选择，发布前检查图片是否正确。

避免把 URL 路径写成现有首页、后台、接口或内置专题入口，例如 `admin`、`api`、`product-sourcing`、`services/bulk-procurement`。已有固定专题有专门的渲染逻辑，新建同名文章不会自动替换它。

点击“保存草稿”。草稿不会成为已发布的前台内容。保存后重新检查站点、语言和路径；如目标选错，先不要发布。

### 第四步：发布前再检查

1. 右侧目标站点是不是发布确认单上的站点？
2. 内容语言是否正确？
3. URL 路径是否正确？能否拼出你预期的完整线上地址？
4. 标题、正文、图片和 Meta Description 是否完整？
5. 发布时间是否为当前或过去时间？如果填未来时间，点击“立即发布”后仍需等到指定时间才开放。

页面中的“预览”主要预览正文排版，不能代替对完整前台地址、目标站点和实际发布状态的检查。

### 第五步：立即发布并实际打开验证

1. 点击“立即发布”，等待出现“内容已发布”。
2. 回到文章列表，将“内容范围”设为“当前站点”，确认该行站点、语言和状态。
3. 手动打开发布确认单里的完整线上地址，检查标题、正文和图片。
4. 若页面未立即变化，刷新页面，必要时等待约 60 秒后再检查。

**当前版本的部分“查看前台 / 打开前台页面”按钮仍优先生成 `http://localhost:8081` 等本地预览地址。线上核验请使用本手册的 IP 地址拼接规则。出现 localhost 不代表内容被发到了其他网站，它是预览链接生成方式的问题。**

如果你预期发英语站，地址栏应是 `https://170.106.116.93/你的路径`；若出现 `/preview/france/`，就不是英语主站的查看地址，应回后台核对目标记录。

## 5. 修改已发布内容、撤回与误发处理

### 修改已发布内容

在列表中核对站点、语言、标题，打开对应记录编辑，修改后点击“立即发布”以保持公开状态。

**当前“保存草稿”会把该版本状态改为草稿；对已发布文章点击它，会使该版本撤回，缓存更新后前台不再公开该内容。“提交审核”也不是继续公开发布的按钮。**

因此，正在公开展示的文章如果只想更新正文，修改后使用“立即发布”；如果想撤下文章，则使用“保存草稿”，并验证原地址。

### 误发到错误站点

1. 在“所有可访问站点”范围内按标题找到误发的那一行，核对行内站点和语言，避免撤回了正确版本。
2. 打开错误版本，点击“保存草稿”，将它撤回。
3. 刷新原来的错误地址，必要时等待约 60 秒，确认不再展示文章内容。
4. 回到正确站点，新建正确版本并重新检查四项发布确认信息。正文可复制，站点与语言需在首次保存前选对。
5. 再发布并核验正确地址。

如果同一内容已有多个语言版本，应以“站点 + 语言”区分记录，不能只看相同的文章标题或内容组。

## 6. 多语言发布与批量操作

常规方式是先写好英语主站文章并发布，再使用“AI 同步其他语言”。

1. 在已发布英语内容的编辑页点击“AI 同步其他语言”。
2. 仔细核对目标站点、语言，选择本次需要的目标。
3. 生成结果是需要人工检查的语言版本，不能把“已生成”理解为“已上线”。
4. 分别打开目标版本，审核语言、正文、SEO、目标站点和 URL，再逐条发布。
5. 当前其他语言站按第 2 节的 `/preview/站点代码/内容路径` 查看。

不需要多语言版本时，只操作英语内容即可。

内容列表可切换为“所有可访问站点”，这会同时展示多个站点的记录。“批量发布”会按勾选的各行站点和语言处理，可能一次影响多个站点。首次操作建议使用“当前站点”范围并逐条发布。

## 7. 文章、单页面、产品和“发布管理”的区别

| 操作 | 用途 | 如何确认目标 |
| --- | --- | --- |
| 新建文章 | 新闻、指南、博客内容 | 编辑页右侧目标站点 + 语言 |
| 新建单页面 | 关于我们、联系、普通服务说明等 | 同上，同时核对页面模板 |
| 新建产品 | 产品介绍及图库 | 同上，同时核对主图和图库 |
| AI 同步其他语言 | 创建指定语言站的内容版本 | 同步对话框的目标 + 各版本编辑页 |
| 内容列表的批量发布 | 一次更改多个已选内容版本 | 每一行的站点、语言、勾选数量 |
| 发布管理 | 站点 / 语言发布检查与发布记录 | 任务中的站点、语言和范围 |

日常发文章在内容编辑页点击“立即发布”即可。当前系统动态读取数据库渲染页面，**不需要先去“发布管理”再点一次，也不需要重新部署服务器程序**。发布管理任务本身不会把草稿文章变为已发布。

新发文章获得自己的内容地址，不会自动替换整个首页。是否出现在首页、栏目或导航，还取决于模板和栏目配置；“首页没看到”不等于没发布，应先打开文章的直接地址检查。

## 8. 当前搜索引擎和邮件状态

- 按 2026-10-22 的要求，线上全站 robots 已设置 `User-agent: *`、`Disallow: /`，响应头包含禁止索引规则。发布文章后，普通访客仍可通过链接访问，搜索引擎应遵守禁止抓取策略。
- 发布文章不会解除全站禁抓，也不会保证搜索引擎收录。后台内容级 SEO 选项不能覆盖当前 Nginx 的全站禁抓配置。
- robots 禁抓不等于访问密码；需要保密的内容应保留草稿，不能仅靠 robots 隐藏。
- 邮件转发针对访客提交表单；点击文章“立即发布”本身不会向收件邮箱转发整篇文章。
