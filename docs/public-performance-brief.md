# 多语言公开页面加载优化 · 2026-10-16

本轮接续整站检查，处理多语言前端整包加载过大的问题。沿用用户已确认的十个专题结构、各国语言视觉风格和参考文案，没有重写正文、修改 CMS 文章或提交业务询盘。

## 已实施

- 六国语言专题改为只加载当前语言内容与组件；FR/ES/IT 首页和 NL 首页只加载当前首页依赖。
- 保留服务端预渲染正文；按 Vite 依赖图输出当前语言的 modulepreload，避免把其他国家和历史模板详情包提前下载。
- 入口脚本使用内容哈希文件名，避免入口被查询参数与静态导入分别执行，重复挂载 React。
- 下载失败时保留正文，提供当前语言错误提示和重试按钮。未通过故障注入验证断网场景。
- 修复优化过程中发现的旧 hash 详情路由兼容问题：访问时才下载完整模板，返回首页仍可用。
- 修复荷语首页带 hreflang 的详情链接被共享导航脚本误拦截的问题；只有地址和锚点均相同的语言入口才阻止重复导航。所有引用位置更新缓存版本。
