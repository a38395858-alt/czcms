# 报关编码详情页设计方案

交付为英文网站效果图与可切换国家的静态排版原稿。本轮不改现有查询功能，不发布线上页面。

- [中国报关完整详情效果图](customs-detail-china-concept-v1.png)：覆盖所给截图中的商品资料、进口/出口税率、检验检疫类别、协定税率、RCEP、所属章节与 13 位 CIQ。
- [美国 HTS 详情效果图](customs-detail-us-concept-v1.png)：展示美国归类、General / Special / Column 2 税率、原产地措施核对、完整法定归类和申报提示。
- [静态排版原稿](customs-code-details-concept-v1.html)：顶部标签可切换美国与中国视图，右侧目录可跳转，提供编码复制。

## 页面结构

页面沿用 FreightVanta 蓝白配色与原有导航。上方先明确适用国家，再提供编码/英文商品名搜索。详情顶部展示编码、商品名称、描述、状态、单位与数据日期；下方按税率、监管检验、协定/RCEP、章节、CIQ 分区。右侧显示目录、数据来源和版本，便于长页面定位。桌面表格在窄屏改为纵向分区。

| 信息模块 | 美国数据 | 中国数据 |
| --- | --- | --- |
| 编码、名称、法定描述、计量单位、归类层级 | 当前官方 HTS 数据具备 | 需要单独的中国税则数据 |
| 数据状态、版本、生效/更新时间 | 展示实际版本记录；不声称行政有效状态 | 需要对应来源与有效状态 |
| General 常规税率 | 当前查询已提供 | 应使用中国的最惠国/普通税率字段 |
| Special 优惠税率、Column 2 | 官方原始导出具备，可扩展现有接口 | 采用中国对应的协定税率体系 |
| 出口税率、退税率、增值税、消费税、进出口暂定税率 | 不套用中国字段 | 需要接入相应中国数据 |
| 检验检疫 N/M、监管条件、13 位 CIQ | 不作为美国 HTS 信息显示 | 需要相应中国监管与 CIQ 数据 |
| RCEP 与中国签订的协定税率 | 不混入美国税率 | 需要中国税则及原产地适用数据 |

## 查询交互建议

1. 搜索前明确选择美国或中国。前 6 位国际 HS 归类可相近，国家扩展编码及税率独立匹配，不把一个国家的完整编码直接当成另一国家编码。
2. 完整编码命中后打开详情；前缀或商品名返回列表，点击具体编码进入详情。
3. 支持复制 10 位商品编码、完整商品资料及单条 13 位 CIQ。协定税率按原产地检索，并显示适用条件与来源日期。
4. 缺失值显示“未提供/待核验”，不得自动填成 0%；税率无数据、过期、更新失败须区分状态。优惠税率为替代待遇，不相加，不默认每票货物都符合优惠资格。
5. 详情保留版本与来源链接，提示基础税率不等于全部应付税费。中国记录的 VAT、退税、CIQ 与美国记录的 Chapter 99 等措施各自展示。

## 样例与验证范围

中国图采用用户四张截图中的 `3909500000`：MFN 6.5%、普通税率 45%、VAT 13%、出口退税 13% 等均为参考图示例，未独立核验当前有效性。参考更新时间为 2026-08-23。空缺税率显示未提供，未补造监管条件。英文名称与 CIQ 描述为参考翻译，中文官方原文优先。

美国图采用本地已核验的 USITC `2026HTSRev22` 原始导出：`3909505000`，法定末级描述 `Other`，General 6.3%，Special 为符合条件时 Free，Column 2 为 `15.4¢/kg + 51.5%`，单位 kg。Special 与 Column 2 是详情设计中的扩展字段，当前已交付查询接口仍以 General 为主。图中原产地选择不执行附加税计算。

两张图片均从 HTML 精确排版导出，非 AI 生图。已检查全部区块、编码和长描述，1440px 桌面及 390px 窄屏均无横向溢出，无页面脚本错误；PNG 具有来源元数据及同名 JSON 旁车。重现命令：`node scripts/render-customs-code-concepts.cjs`。本轮只完成设计稿，数据接入与正式详情路由留待功能实现。
