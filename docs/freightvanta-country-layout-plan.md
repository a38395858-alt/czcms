# 六国前台排版方案 · 2026-10-15

## 覆盖与依据

从六站首页导航、专题 manifest 和站点地图发现 100 个可访问 HTML 页面：英语 28、德语 18、法语 18、西语 12、意语 12、荷语 12。包括 6 首页、60 专题、6 资源索引和 28 篇内容/分类/标签页。初审 200 个桌面/手机场景，另检 768/320px。证据：`output/country-layout-review/inventory.json`、`before.json` 和页面截图。

另有 14 个联系/法律链接返回 404，未计入可访问页面。此次不擅自编写联系和法律内容，将缺失页面列为后续内容配置事项。

## 已确认问题

- 英语首页首屏 1017px，高度被 81px 窄栏标题拉长；桌面主要板块上下间距约 130px，阅读路径过长。
- 德语首页首屏约 963px；40px 的语言按钮需增大。部分德法资源/分类/文章页面在 320px 横向溢出。
- 法/西/意首页段落区块统一 128px 上下留白；首屏到询盘前内容冗长。西意询盘区超过 2100px；应改善左右比例、表单宽度及组间距，而非删除文案。
- 四种导入语言的宽图专题标题仍被旧 `max-width` 限制，部分首屏出现过多换行；横向流程 6 步可能排成 5+1，末步孤立。
- 专题相关服务与行业链接全部单列时占据大量高度，需要保留文案的紧凑网格。
- 首页部分远程图片无法解码，影响图片区域和页面可信度。
- 法意首页 Cookie 区域在窄屏遮挡过多内容；应在保留说明、同意和拒绝操作的前提下设置可滚动说明区域及稳定按钮位置。
- 资源和文章模板仍用旧配色，偏离对应国家首页。应仅对内容模板应用国家色彩令牌，不重置各首页视觉身份。

## 排版实施

1. 首页建立一致节奏：桌面区块上下 72–88px、手机 44–52px；区块内标题与正文 20–28px。保留各国首页布局差异。
2. 英语首屏将标题栏拓宽，字号控制在约 54–64px；图片保留独立区域。德国减小标题与内容间距和图片上下留白。
3. 法语保留衬线与海港图分栏；西语保留并排标题/导语及横幅图；意语保留 Bodoni 与运单信息、压缩宽幅图片高度；荷语保留 Archivo Black 与港口横幅。
4. 专题维持 10 组结构：宽图首屏标题约 40–46px，正文与标题两栏可读；纵向流程保留，横向流程使用 3×2（窄桌面 2×3），手机单列；范围、准备清单、相关服务避免窄栏与单个孤立项。
5. 表单区域：桌面说明约 4/12、表单约 8/12，表单宽度有上限；字段约 16–24px 间距，移动端按原 DOM 顺序单列。
6. 资源页：标题、摘要与图文同屏，图片字幕置于图片边界内；文章正文约 65–75ch，侧栏在中窄屏回归单列。长标签及标题自然换行，内容容器 `min-width:0`。
7. 图片优先本地缓存原始摄影，保留原图语义，不新增事实或承诺。

## 保留与验证

用户提供的正文、标题、FAQ、业务边界均保留；只调整结构、样式和资源路径。修改后对同一 100 页执行一次确认矩阵，比较正文哈希、截图、溢出、图片、H1 和脚本错误。表单提交仅检查校验，不产生真实询盘。保留现有工作区修改，不提交或发布。
