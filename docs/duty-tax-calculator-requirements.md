# 关税与进口增值税预估器：需求文档（PRD）

- 项目：CZCMS / FreightVanta
- 功能英文名：Import Duty & Tax Calculator
- 需求版本：v1.0 草案
- 编写日期：2026-11-10（Asia/Shanghai）
- 状态：待产品负责人确认，尚未实现；本文不代表已经接入税费数据或完成上线。
- 配套文档：[技术开发文档](<duty-tax-calculator-development.md>)

## 1. 产品目标

为跨境卖家、采购商和物流客户提供有来源、可解释的进口费用预算工具。用户输入目的地、原产国、目的地商品编码、货值及相关运输费用，获得适用范围内的关税、进口 VAT、政府规费、商业清关服务费和到岸成本参考，并可将条件带入 FreightVanta 询盘。

核心价值不是“永远给出一个数字”，而是说明：**哪些费用已经计算、哪些只是用户假设、哪些尚未覆盖，以及还需要什么资料。**

### 1.1 必须达成

1. 减少销售反复追问货值、原产国、编码和运费的次数。
2. 帮助客户理解关税、进口 VAT、政府规费和清关服务费的区别。
3. 解释 DDP 与 DAP 下的常规费用责任，不因切换交货条款修改法定税额。
4. 接入现有编码查询与询盘链路，不另建一套独立内容系统。
5. 每项自动税率有来源、版本和适用日期；未确定项目不按零计算。
6. 不鼓励低报货值、拆单避税或错误归类；货值应为真实交易及适用估价规则下的金额。

### 1.2 不承诺

- 不替代海关裁定、报关申报或报关行核价。
- 不保证海关最终接受商品编码、原产地、估价或优惠资格。
- 不承诺自动识别所有附加税、反倾销税、反补贴税、配额及特殊程序。
- 不把本工具结果当作 FreightVanta 已接受的 DDP 报价或代缴承诺。
- 不把进口 VAT 的预算金额等同于不可抵扣成本或当场实付现金。

### U1 跨境卖家

“我从中国进口一批商品到德国，货值和运费已知，想知道进口税费的大致构成。”

### U2 采购商 / 收货人

“供应商说是 DAP，我想知道还可能由我承担哪些进口费用，而不是误以为没有税。”

“客户从编码页进入询价，已带上商品、价值、费用假设和缺失项，我可以据此复核报价。”

“税率、VAT、规费和服务费有变化，需要看到来源、有效期、影响范围，审核后发布并能停用。”

### 4.2 V1.0 支持的业务情形

- 单票、单一商品行、单一原产国、一个进口国与同国交货地点。
- 一般商业进口，关税以已验证的从价税规则为主。
- 海运、空运、公路/铁路和快递的运输模式输入；承运商专项收费仅在有规则时适用。
- DDP 与 DAP 责任说明；“DDU”只作历史叫法的搜索和说明文字，数据库统一为 DAP。
- 一个报价输入币种；货值和新增费用统一该币种，再转换到目的地税费币种。
- 原币种已是税费币种，或已有审核汇率；无官方汇率可做明确标注的手动汇率情景预算。
- 支持受限人工税率情景，但不能伪装成自动查得的官方适用税率。

### 4.3 V1.0 不自动完成的情形

- 多商品混装、跨国清关后再转运到另一欧盟国家、特殊海关程序。
- IOSS、平台代征、英国特殊低货值销售 VAT 程序、免税/减免资格自动判定。
- 烟酒、能源等消费税；CBAM 金额；农产品复杂税率；从量税及复合税。
- 配额、许可证、最终用途、加工贸易、暂时进口、保税、退运和二手特殊估价。
- 自动优惠原产地资格判定、反倾销/反补贴的制造商条件及未知附加编码。
- 北爱尔兰、海关/VAT 特殊领土、海外地区；地址落入特殊范围时进入人工审核。
- 美国州销售税、使用税；其他国家 GST（V1.0 只是为未来扩展预留名字）。
- 进口 VAT 抵扣资格审核、递延缴纳开户、实际代缴、自动报关和在线付款。

以上不是隐藏限制：应在表单或结果中就近说明；不可通过免责声明掩盖错误的完整总额。

## 5. 核心业务原则

### BR-01 输入三项并不足以完成测算

“目的国 + HS Code + 申报价值”只能作为起点。至少还需要原产国、进口日期、估价口径及按国家要求的运输/保险费用；是否低货值、是否特殊商品也影响流程。

### BR-02 HS 六位不等于完整进口编码

- 允许六位输入辅助检索，不自动补零、截断或当作最终归类。
- 展示候选商品描述，要求确认目的地完整编码。
- 美国、欧盟和英国扩展位数不能直接跨市场复用。
- 同时保留用户原输入与规范化编码，前导零不得丢失。

### BR-03 原产地与日期必须参与规则选择

税率按进口法域、有效日期、原产国、商品编码、程序和条件匹配。起运港不构成原产地证明；未来日期或历史日期无数据时，不用当前税率冒充。

### BR-04 缺失、零、不适用严格分开

- 已确认零税率：显示 0.00 与依据。
- 不适用：显示“不适用”，例如美国进口 VAT。
- 未覆盖/无法确定：显示“待核实”，金额为空，不显示 0.00。
- 客户不知道运费：允许保存条件或询价，不允许悄悄当运费为零。

### BR-05 基础税率不是全部税负

美国 General / 欧盟第三国税率不等于完整进口税负。脚注、额外措施和适用条件未核清时，只能给已知费用小计。不能把 Special、Other 或 TARIC 中所有百分比加在一起。

### BR-06 DDP / DAP 不改变税额

切换条款只改变一般责任提示和展示分组，不改变归类、估价或法定税率。DDP 通常由卖方承担进口手续与税费，DAP 通常由买方处理进口手续与税费；合同、进口商资质及当地法规仍需确认。不得显示“选 DDP 即可合法使用我们的进口商/VAT 号”。

### BR-07 财税成本与现金支付分开

进口 VAT 作为预算项目展示，不默认抵扣，也不因客户有 VAT 号码直接免除。递延、反向机制等不在 V1 自动处理范围内；存在此类安排时，税负预算与到港现金支出不能画等号。

### BR-08 费用不得重复计入

发票可能已含运费、保险、服务费，税基和成本合计必须逐项处理。申报海关价值属于计算基数，不得再叠加到货值、运费构成的实际成本上。DDP 含税整包发票未拆分时，不自动倒推出不可靠税额。

## 6. 访客流程

1. 从页脚工具入口、HTS/TARIC 详情或运费结果进入。
2. 选择目的国、适用地区、原产国、预计进口日期和 DDP / DAP。
3. 输入/确认目的地完整商品编码及商品描述。
4. 输入真实商品货值、币种、运费保险和已包含关系；必要时补充海关价值。
5. 确认适用 VAT 类别、规则条件、费用假设和未覆盖特殊情形。
6. 点击“预估进口费用”，获得金额明细、计算过程、来源与覆盖状态。
7. 修改任一关键输入后旧结果标记失效，重新计算；不继续展示旧“总额”。
8. 可打印/复制摘要；选择“请 FreightVanta 核实并报价”后，客户确认隐私与联系方式再提交询盘。

不需要为了看预估结果先注册或留下邮箱；计算本身不发送邮件、不自动创建销售线索。

## 7. 输入要求

| 字段 | 要求 | 校验与说明 |
| --- | --- | --- |
| destination_country | 必填，已启用目的国 | 不接受 EU 泛称；每国 VAT 单独匹配 |
| destination_region | 必须确认适用范围 | 本土/特殊地区；特殊地区人工处理 |
| delivery_country | 默认等于进口国并确认 | 不同则 V1 不支持自动测算 |
| origin_country | 必填 | 原产地，不是发货地 |
| import_date | 必填，可默认目的法域当天 | 默认日期可见；不得无提示切换时区 |
| commodity_code | 必填 | 支持分隔符规范化；完整编码核验后才能自动测算 |

| goods_value | 必填，正数 | 单票总商品价值，不再乘件数；不含可分离税费 |
| valuation_mode | 必填 | guided（分项估价）/ declared_customs_value（已确认海关价值） |
| freight_to_border、insurance_to_border | 按估价要求补充 | null=未知；0 需要明确确认免费或不适用；已含发票须标识 |

| declared_customs_value | 高级模式必填 | 与货物实际成本分开；已由客户/报关行确认的数额 |

## 8. 结果要求

### 8.1 结果结构

1. 当前国家、原产地、编码、日期、条款及币种。
2. 状态标签和一句话覆盖说明，放在数字之前或同一视觉层级。
3. 关税明细：基础关税、已核实附加措施、未知/条件未满足措施。
4. 进口 VAT：适用税率、计税基数、包含哪些费用；美国显示不适用。
5. 政府规费：仅适用的规则，按票而非商品数量重复计征。
6. 商业费用：报关、垫付等与政府规费分组；明确非政府统一税费。
7. 已知税费小计、已知进口附加成本小计、具备条件时的到岸成本参考。
8. 未计入项目、用户假设、数据新鲜度和官方链接。
9. DDP / DAP 常规费用责任说明及“核实并报价”按钮。

### 8.2 状态与金额口径

| 状态 | 展示 | 允许的总额 |
| --- | --- | --- |
| estimated | 当前受支持范围、必需输入与有效规则齐全 | “支持范围内的费用预估”，仍保留排除项与假设，不称最终税单 |
| partial | 有可计算项，但存在缺失费用或措施 | 仅“已知费用小计”；完整税费/到岸总额为空 |
| manual_review | 涉及特殊程序、复杂税率、人工税率或关键估价不确定 | 展示可解释部分/情景值，主提示为人工核实；不出完整总额 |
| unsupported | 国家、地区或业务流程未支持 | 不输出误导性金额；保留输入与询价入口 |

输入错误是表单校验错误，不伪装成业务估算状态。VAT 所依赖的关税未知时，不能把已知基础关税代入后把 VAT 标成完整；只可提供“基于已知部分的情景值”，不计入正式已知税费小计。

### 8.3 三种不可混淆的合计

- 关税与进口 VAT 小计：只含已确认可计算的税项。
- 进口附加成本：税项 + 政府规费 + 已提供商业清关费用，按各自范围说明。
- 到岸成本参考：实际商品成本 + 不重复的运输/保险/服务费用 + 税费。海关价值不是额外成本行。

缺少清关服务费时可以显示已知税项，但不得声称是全部清关成本。所有未知项必须在小计附近可见。

## 9. 国家规则要求

### 9.1 美国

- 不征收欧盟式联邦进口 VAT；不以“美国 VAT=0%”概括所有美国税种。
- Customs Value 不统一套用 CIF；有符合规则且分列的国际运费/保险时按美国估价规则处理。
- General、Special、Other 为不同税率待遇；不能相加，也不能自动选择最低值。
- Chapter 99、贸易救济、临时附加措施和排除必须有适用性及有效期；没有覆盖就提示未知，尤其不能只显示 General 后称“美国进口总税费”。
- MPF、HMF 的适用范围、税基、比例、最低/最高额、豁免及生效日期由规则管理；不把 HMF 加到全部空运/快递。
- 低货值/小额进口政策不写死固定金额免税，需在上线时按现行制度和进口方式核验。

### 9.2 欧盟五国

- 关税以已审核 TARIC 措施为基础；国别 VAT 独立维护。
- 进口 VAT 一般从海关价值加适用税费和未重复纳入的相关附带费用计算，而不只是货值乘 VAT。
- 各国标准、减低、零税率必须有适用范围；默认标准税率只是待确认建议。
- 特殊领土不自动套用本土 VAT，例如加那利、休达、梅利利亚以及其他特殊地区。
- 优惠、配额、反倾销、消费税、CBAM 等条件不能简单忽略；识别风险后进入人工核实或部分结果。
- 不自动套用旧版 150 欧元规则；不把 IOSS 与一般进口 VAT 计算混用。

### 9.3 英国

- 使用英国税则与商品适用 VAT，不复用欧盟完整编码的税率。
- 仅 GB 常规进口；北爱尔兰及特殊地区单独提示未支持。
- VAT 税基包含按规则纳入的相关费用与关税；不是只对货值征 VAT。
- 标准 20% 只是文档编写时官方公布的一类税率，不是所有商品的固定税率。
- 低货值销售 VAT、平台代征和 postponed VAT accounting 不作为普通边境支付自动计算。

## 10. 后台规则管理

首期必须有最小管理能力，不能长期靠开发人员改前端常量：

- 国家功能开关、支持程序与覆盖状态。
- VAT 类别、范围、来源、有效起止日期与复核到期时间。
- 规费及商业服务费模板，分别维护；商业模板按服务范围/渠道/站点匹配。
- 已审核税则规则与原始文本、代码、原产地、条件、互斥/叠加关系。
- 规则草稿 → 校验 → 审核发布 → 停用/回退。
- 变更预览与固定样例试算，显示受影响国家、编码和日期。
- 查询失败、解析异常、过期规则及覆盖缺口告警。
- 沿用系统权限和审计；禁止不经记录直接修改已发布版本。

首期复用现有 system.manage 管理门禁；正式数据发布建议由独立业务复核人审核。没有第二人的团队至少实行草稿、样例复核和显式发布，不假称已完成双人审核。

## 11. 页面、多语言与 SEO

- 建议正式路径：`/tools/import-duty-tax-calculator`；六站各自提供本地化说明。
- 预览路径沿用 `/preview/{siteCode}/tools/import-duty-tax-calculator`。
- 首期入口：页脚工具区、HTS/TARIC 详情“估算进口费用”、运费结果“加上进口税费”。不强行改现有主导航。
- 前台支持 en / de / fr / es / it / nl；后台中文；英国目的地在英语站可用，不必新增英国独立站。
- 目的地与站点独立：不得因德国站语言是德语就强制德国目的地。
- 无参数介绍页可收录，包含真实功能说明、支持范围、FAQ 与国家差异。
- 带条件/结果页面 noindex、no-store；货值、邮箱、报价和敏感交易信息不得写入 URL。
- 默认不生成公开分享结果；首期可浏览器打印/复制摘要，PDF 独立导出不列为硬依赖。
- 无 JavaScript 能阅读介绍和提交基础计算表单；编码候选可通过服务器步骤确认。
- 错误定位到字段，支持键盘、状态朗读，320/390/768/1440px 无主要内容溢出。

## 12. 安全与隐私

- 试算不要求联系方式、不自动持久化整笔交易；仅提交询盘后保存必要快照。
- 不能相信浏览器传来的税率、总额、站点 ID 或“已经审核”标记。
- 第三方税则调用只发送必要编码/原产国/日期，不发送货值和客户联系方式。
- 不在日志、访问分析、错误上报和 URL 中记录货值及完整表单。
- 公共接口限流、有请求体和超时上限；不接收用户提供的上游 URL。
- 保存的询盘受现有站点/Locale 权限控制；源站/预览保持原有安全策略。
- 规则变更与发布可审计；不向访客暴露内部接口密钥或管理详情。

## 14. 分期与交付物

- 抽取真实编码校对；由熟悉报关的业务人员核对规则与文案。
- 英国上游、VAT 类别、美国附加措施、汇率和服务费没有完成验证时明确记录缺口。

### M1 核心计算与受控数据

- 固定精度引擎、国家估价策略、税率适配、覆盖状态和版本化规则。

- 单元/集成/浏览器/安全与真实样例复核。

## 15. 成功指标

- 计算成功率分母仅为已支持且有效的请求；另报 partial/manual_review/unsupported 占比。
- 编码确认 → 计算 → 询价漏斗；无须记录具体货值即可统计。
- 规则过期数、数据源失败率、解析覆盖率、人工复核发现差异数。
- 询盘资料完整率及销售补问次数变化。
- 不以“全部请求都出总额”或虚构准确率作为目标。

## 16. 待确认事项（建议默认方案）

1. 首期国家：建议美国 + 欧洲五国 + GB；其他欧盟国家后续逐国审核启用。
2. 首期一般商业进口、单商品；特殊程序明确转人工。
3. 商业清关费：有审核模板才自动填，否则未知，不写一个通用固定价。
4. 标准 VAT：提供建议但要求用户确认适用类别；商品减免不凭名称猜测。
5. 初期不接付费税费服务；若要求广泛的美国附加税/复杂商品自动覆盖，需评估正式数据服务与预算。
6. 默认不保存匿名试算、不提供公开分享、不新增客户账号系统。
7. 上线审核人、国家税率维护人、规则失效通知收件人需在开发启动时明确。

## 17. 官方依据与核验说明

以下为 2026-11-10 查阅的规则入口，不是所有国家费率已审核的证明。动态政策必须在实现与上线时再次核实。

- [欧盟委员会：进口 VAT 计税基础（Articles 85–87）](https://taxation-customs.ec.europa.eu/taxation/vat/vat-directive/taxable-amount_en)：海关价值、相关税费及未重复纳入的附带费用。
- [欧盟委员会：VAT Rates](https://taxation-customs.ec.europa.eu/taxation/vat/vat-directive/vat-rates_en)：成员国决定税率和适用类别；TEDB/各国主管机关为进一步核验入口。
- [欧盟委员会：TARIC](https://taxation-customs.ec.europa.eu/online-services/online-services-and-databases-customs/eu-customs-tariff-taric_en)：多种税则及贸易措施；不包含各国 VAT 与消费税。
- [HMRC：进口 VAT 价值](https://www.gov.uk/guidance/working-out-the-vat-value-using-the-customs-value-of-the-imported-goods)：关税价值与进口 VAT 价值不同，相关费用按规则加入。
- [英国 VAT 类别](https://www.gov.uk/vat-rates)：标准、减低和零税率并存，不应全部固定为 20%。
- [英国 Trade Tariff](https://www.gov.uk/trade-tariff)：英国商品编码、Duty 与 VAT 查询官方入口；本轮 API 地址访问返回 403，接口可用性及授权尚待验证。
- [CBP User Fee Table](https://www.cbp.gov/trade/basic-import-export/user-fee-table)：MPF、HMF 等费用及法律依据；网页注明可能有更新滞后，不能直接照抄为当前生效费率。
- [ICC Incoterms 2020](https://iccwbo.org/business-solutions/incoterms-rules/incoterms-2020/)：术语版本及权利方入口；具体合同责任须由业务核对，不复制付费规则全文。

美国估价、最新附加措施/排除、各国 VAT 适用类别、各国海关汇率、低货值制度及特殊地区清单均列为 M0 必须追加的法源核验任务。本文件不使用未经验证的当前附加税率或免税门槛。
